# LightPath Reusable Data Format Specification

This document specifies the open, machine-readable data schema used for publishing celestial visibility window tables generated by the **LightPath** astrodynamics pipeline.

All datasets are distributed in dual formats:
1. **RFC 4180 CSV** (UTF-8, comma-delimited, with standard header).
2. **Apache Parquet** (columnar, Snappy-compressed, with embedded schema metadata).

---

## 1. Window Table Column Schema

| Column Name | Data Type (PyArrow / SQL) | Units / Representation | Description |
| :--- | :--- | :--- | :--- |
| `site_id` | `pa.string()` / `VARCHAR` | Alphanumeric slug | Unique identifier of the lunar landing site or region (e.g., `synthetic-proving-ground`, `shackleton-connecting-ridge`). |
| `target` | `pa.string()` / `VARCHAR` | Categorical | Target visibility condition: `sun` (solar disc), `earth` (Earth disc), `dte` (Direct-to-Earth DSN station line of sight), or `joint` (Sun AND DTE line of sight). |
| `window_id` | `pa.int32()` / `INTEGER` | 0-indexed count | Sequential identifier of the contiguous visibility window for this site and target. |
| `start_utc` | `pa.string()` / `TIMESTAMP` | ISO 8601 UTC | Timestamp marking the start of the contiguous visibility window (e.g., `2026-11-01T00:00:00Z`). |
| `end_utc` | `pa.string()` / `TIMESTAMP` | ISO 8601 UTC | Timestamp marking the end of the contiguous visibility window. |
| `duration_h` | `pa.float64()` / `DOUBLE` | Decimal hours (`_h`) | Contiguous duration of visibility in hours. |
| `threshold_pct` | `pa.float64()` / `DOUBLE` | Percentage or degrees (`_pct`) | Applied visibility threshold: disc visible fraction percentage (e.g. `50.0`%) for `sun`, `earth`, and `joint`; or minimum ground-station elevation angle (e.g. `10.0`°) for `dte`. |
| `mast_height_m` | `pa.float64()` / `DOUBLE` | Meters (`_m`) | Observer mast elevation above local terrain ground in meters. |
| `is_synthetic` | `pa.bool_()` / `BOOLEAN` | `true` / `false` | Distinguishes synthetic benchmark models (`true`) from real lunar data (`false`) in compliance with Project Rule 3. |
| `ephemeris_source` | `pa.string()` / `VARCHAR` | Categorical | Source of ephemeris trajectory: `analytic_approximation` or `spice_kernels`. |
| `terrain_source` | `pa.string()` / `VARCHAR` | Categorical | Source of digital elevation model: `synthetic` or `lola_dem`. |
| `provenance_hash`| `pa.string()` / `VARCHAR(8)` | Hexadecimal string | Short 8-character SHA-256 hash tracing the calculation to its exact DEM, SPICE kernels, and pipeline parameters. |

## 2. Embedded Parquet Key-Value Metadata

Parquet files embed standard machine-readable metadata in the file footer (`FileMetaData.key_value_metadata`):

| Metadata Key | Value | Purpose |
| :--- | :--- | :--- |
| `schema_version` | `1.0.0` | Semantic version of the window table specification. |
| `coordinate_frame` | `MOON_ME` | Declares the lunar reference frame (Moon Mean Earth/Polar Axis frame, Rule 5). |
| `elevation_formula` | `exact_spherical_curvature` | Declares that topocentric elevation accounts for lunar spherical curvature (Rule 7). |
| `r_moon_m` | `1737400.0` | Mean lunar reference sphere radius in meters ($R = 1,737.4\text{ km}$). |
| `license_data` | `CC-BY-4.0` | Creative Commons Attribution 4.0 International for data files. |
| `license_code` | `MIT` | MIT License for pipeline code and algorithms. |
| `units_duration` | `hours` | Declares duration measurement unit. |
| `units_mast_height` | `meters` | Declares mast elevation measurement unit. |
| `units_threshold` | `percent_disc_fraction_or_degrees` | Declares threshold measurement unit. |

## 3. Mathematical Consistency Contract

In compliance with **Rule 1 (Correctness)**, the exported window tables satisfy strict conservation properties:

1. **Duration Summation Parity**:
   For each target ($T \in \{\text{sun}, \text{earth}, \text{dte}, \text{joint}\}$):
   $$\sum_{i=0}^{N_w - 1} \text{duration\_h}_i = \text{total\_uptime\_h} = N_{\text{active}} \times \Delta t$$
   Where $N_{\text{active}}$ is the exact count of active time steps in the corresponding `series.json`, and $\Delta t$ is the simulation time step in hours.

2. **Downtime Continuity**:
   Outage periods between adjacent windows $[W_i, W_{i+1}]$ must satisfy:
   $$\text{outage\_duration}_i = \text{start\_utc}(W_{i+1}) - \text{end\_utc}(W_i)$$
   The maximum gap across the time domain strictly equals `longest_outage_h` reported in `stats.json`.

## 4. Example Inspection

### Reading in Python (PyArrow)
```python
import pyarrow.parquet as pq

table = pq.read_table("web/public/data/all_sites_windows.parquet")
print("Schema:")
print(table.schema)
print("\nEmbedded Metadata:")
for k, v in table.schema.metadata.items():
    print(f"  {k.decode()}: {v.decode()}")

df = table.to_pandas()
print(df.head())
```

### Reading in R
```r
library(arrow)
df <- read_parquet("all_sites_windows.parquet")
summary(df)
```
