# `data/`

This directory stores raw input datasets and processed simulation outputs for LightPath.

## Subdirectories
- `raw/`: Unprocessed Digital Elevation Models (DEMs) from NASA LOLA (LRO) and PDS archives. Managed via `scripts/fetch_dem.py` and `dem_manifest.json`.
- `processed/`: Schema-validated simulation outputs generated by `scripts/run_pipeline.py`. Contains site-specific folders with `site.json`, `horizon.json`, `series.json`, `stats.json`, `visibility_cube.json`, `route_result.json`, `provenance.json`, and `run_info.json`.
